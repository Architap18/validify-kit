      CAPABILITIES

      Everything You Need for Validation

      🗂️

      Schema-Driven Validation

      Define rules once in a plain JS object. validify-kit enforces them automatically on every request — no repetitive if-statements.

      📧

      Email Validation

      RFC-compliant email format check with email: true. Pair with lowercase: true for automatic normalisation.

      🔐

      Strong Password Checks

      Enforce uppercase, lowercase, number and specialChar requirements in one schema field.

      🔢

      Number & Range Validation

      type: 'number' with min / max enforces numeric bounds — perfect for age, price or quantity fields.

      📋

      Array Validation

      type: 'array' with minItems, maxItems and uniqueItems validates list fields including per-item schemas.

      🔍

      Regex Pattern Validation

      Pass any RegExp as the pattern rule — used here to validate international phone numbers with strict digit-count enforcement.

      🧹

      Input Sanitization

      trim, lowercase and uppercase transforms run before validation. Original req.body is never mutated.

      🔗

      Express Middleware

      validateRequest(schema) drops into any Express route. Auto-returns HTTP 400 on failure; passes sanitized data via req.sanitizedBody.

      ⚙️

      Custom Validators

      Use custom: (value) => boolean for any logic not covered by built-in rules — including cross-field checks and async-free business rules.

      INTEGRATION

      Simple to Integrate

      Drop validateRequest directly into your Express route. One line of middleware replaces dozens of manual checks.

      userRoutes.js 
      const { validateRequest } = require("validify-kit");

// Define your validation schema
const userSchema = {
  name:     { required: true, type: 'string', minLength: 3, trim: true },
  email:    { required: true, email: true },
  password: { required: true, minLength: 8, uppercase: true, specialChar: true },
  age:      { required: true, type: 'number', min: 18 },
  skills:   { required: true, type: 'array', minItems: 1 },
};

// One line of middleware — that's it
app.post(
  "/register",
  validateRequest(userSchema),   // ← validates & sanitizes
  registerController              // ← only called if valid
);
