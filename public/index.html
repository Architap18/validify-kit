    ⚡ Features Demonstrated

    What this app shows about validify-kit

    🗂️

    Schema-Driven Validation

    Define rules once in a plain JS object; validify-kit enforces them automatically on every request.

    🔗

    Express Middleware

    validateRequest(schema) plugs directly into an Express route — no boilerplate required.

    📧

    Email Validation

    The email: true rule checks RFC-compliant format. Combined with lowercase: true for automatic normalisation.

    🔐

    Strong Password Checks

    uppercase, lowercase, number, specialChar rules enforce password strength. isStrongPassword() is also available as a standalone helper.

    🔢

    Number & Range Validation

    type: 'number' with min / max enforces numeric bounds — used here for age ≥ 18.

    📋

    Array Validation

    type: 'array' with minItems: 1 ensures the skills list is non-empty. uniqueItems and per-item schemas are also supported.

    🔍

    Pattern (Regex) Validation

    The pattern rule accepts a RegExp; used here to validate international phone-number formats (8–16 digits, optional + prefix).

    🧹

    Input Sanitization

    trim: true strips whitespace from name & phone. lowercase: true normalises email. The original req.body is never mutated — sanitized data lives in req.sanitizedBody.
